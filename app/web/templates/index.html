Help

      
Quick start
- Enter a prompt and click "Run" for standard chat.
- Use "Run stream" for token-by-token output.
- Keep "Use session memory" enabled if you want multi-turn context.

Task console
- Create task with mode=auto for full execution.
- Use mode=guided to inspect state transitions before finalizing.
- Refresh/List/Events/Cancel controls are in the Task console block.

Agents
- Create an agent with a system prompt and optional model override.
- Enable only required tools in "enabled tools" (least-privilege principle).
- Use "Run agent" for synchronous execution.
- Use "Queue run" for background processing, then check/cancel by run ID.

Online mode
- Enable "Allow online automation" when creating the agent.
- Include web_automation in enabled tools.
- Provide online URL + objective at run time.

Troubleshooting
- Provider health: click "Check providers".
- Auth issues: set API key if auth is enabled.
- If a run fails, inspect run state and error payload in the Response panel.
